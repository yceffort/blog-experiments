# number-flow 포크의 구형 WebKit 화면 확인

[number-flow 포크](https://github.com/yceffort/number-flow)의 selftest는 WebKit 17.4와 18.2에서 폭 스케일과 등장 페이드를 실패로 보고했다. selftest는 값을 `getComputedStyle()`로 읽는다. 이 실험은 같은 장면을 `getComputedStyle()`, 스크린샷, 재생 녹화로 각각 재서 실제 화면에 무엇이 그려지는지 확인한다.

WebKit은 Playwright 1.40.0, 1.49.0, 1.62.1이 고정 배포한 macOS 빌드(17.4, 18.2, 26.5)다. Safari 자체에서 확인한 결과는 아니다.

## 측정

1. **`getComputedStyle()`** (헤드리스): 숫자를 9에서 123456으로, 다시 9로 바꾸는 동안 프레임마다 `.number`의 `scaleX()`, 마스크 모서리 폭, 투명도가 0과 1 사이인 등장 문자 수를 읽는다. 마스크 모서리 폭에 `scaleX()`를 곱하면 계산상 화면 페이드 폭이다.
2. **스크린샷** (헤드리스): `::part(number)`에 검은 배경을 깔아 마스크가 그 가장자리를 흐리게 만들게 한다. 9에서 123456으로 바꾸는 동안 스크린샷을 찍고, 가운데 줄에서 검은 상자의 폭과 불투명도가 5%에서 95%로 오르는 구간(÷0.9)을 페이드 폭으로 읽는다. 애니메이션이 끝난 뒤 마스크 폭을 `1.5em`(48px)으로 바꾼 화면을 대조군으로 찍는다.
3. **재생 녹화** (headed): 구형 WebKit은 헤드리스에서 빈 화면만 녹화되어 창을 띄워 녹화한다. 영상 프레임을 ffmpeg로 잘라 읽는다.
   - 장면 A: 2번과 같은 상자 폭과 페이드 폭. 압축으로 가장자리가 번지므로 20%에서 80% 구간(÷0.6)을 쓴다.
   - 장면 B: 오른쪽 끝을 고정한 5를 -5로 바꾼다. 부호가 최종적으로 놓일 자리에서 가장 진한 픽셀 값이 0.03에서 0.95까지 오르는 시간을 잰다. 투명도 페이드가 그려지면 기본 `opacityTiming`(450ms `ease-out`)에 맞춰 서서히 오르고, 그려지지 않으면 바로 1에 가깝다.
   - 장면 C: 같은 방식으로 9를 19로 바꿀 때 새로 들어오는 1.
   - 장면 D: 장면 B와 같되 `opacityTiming`만 2초 `linear`로 늘린 대조군. 오르는 시간이 함께 늘어나면 B와 C의 변화는 글자의 이동이나 마스크가 아니라 투명도 페이드에서 나온 것이다.

## 실행

```sh
cd number-flow-webkit-mask
node measure.mjs > results/summary.md
```

git, pnpm, npm, ffmpeg가 필요하다. 처음 실행하면 두 커밋을 `work/`에 받아 빌드하고 Playwright 세 버전을 설치한다(약 1.2GB, 커밋하지 않는다). 녹화 중에는 WebKit 창이 잠깐씩 뜬다. 2026-10-07 Apple M5 macOS에서 측정했다. 프레임별 원자료는 `results/*.json`에 있다.

마스크 폭을 `1.5em`으로 바꾼 대조군은 스크린샷에서 47.8px, 녹화에서 48px로 읽혔다.

- `92e7d01`의 selftest 실패는 `getComputedStyle()`이 보고한 값에서만 나타났다. 17.4와 18.2에서 `scaleX()`는 1로 보고됐고, 투명도가 0과 1 사이인 등장 문자는 한 번도 보고되지 않았다.
- 화면에서는 `92e7d01`도 17.4와 18.2에서 폭 스케일(상자 폭이 약 40px에서 135px로 커짐), 마스크 보정(페이드 폭 약 16px 유지), 등장 페이드(약 0.3초에 걸쳐 나타남)가 26.5와 같이 그려졌다.
- 장면 D에서 페이드를 2초로 늘리면 오르는 시간도 약 1.8초로 늘어난다. B와 C의 변화는 투명도 페이드에서 나온 것이다.
- `getComputedStyle()`의 마스크 모서리 폭은 `92e7d01`의 17.4와 18.2에서도 애니메이션 중인 값을 따라갔다. 그래서 `scaleX()`가 1로 보고되는 동안 계산상 페이드 폭은 46px까지 벌어졌지만, 화면의 페이드 폭은 16px 안팎이었다. 같은 요소에서도 속성마다 보고되는 값이 달랐다.
